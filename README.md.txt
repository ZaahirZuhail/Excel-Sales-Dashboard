# Excel Sales Dashboard

## Project Overview
An interactive Sales Dashboard developed using Microsoft Excel to analyze sales performance and visualize important business insights.

## Objectives
- Analyze sales data.
- Identify sales trends and patterns.
- Monitor sales performance.
- Present insights through interactive visualizations.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization

## Dashboard Features
- Interactive sales dashboard.
- Sales performance analysis.
- Dynamic filtering using slicers.
- Visual representation of sales data.

- Sales_Dashboard.xlsx – Excel project file.
